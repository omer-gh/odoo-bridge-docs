# Code of Conduct

This is a small, single-maintainer project. It's not actively soliciting
contributions, but the issue tracker is open for questions, bug reports,
and security concerns (see [SECURITY.md](SECURITY.md)).

If you interact with this project — filing an issue, commenting, or
anything else — keep it civil and on-topic:

- Be respectful. Disagreement is fine; personal attacks, harassment, or
  discriminatory language aren't.
- Stay constructive. A bug report or question is welcome; venting isn't
  the same as feedback.
- No spam, no off-topic promotion.

Reports of conduct issues, same as security concerns, can go through the
issue tracker on this repo.
